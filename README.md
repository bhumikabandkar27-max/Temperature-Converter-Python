Temperature Converter Using Python

About

This is a beginner-friendly temperature converter developed using Python and Tkinter.

Features

- Convert Celsius to Fahrenheit.
- Convert Fahrenheit to Celsius.
- Simple graphical user interface.
- Input validation.
- Error handling for invalid inputs.

Technologies Used

- Python
- Tkinter

Conversion Formulas

- Fahrenheit = (Celsius × 9/5) + 32
- Celsius = (Fahrenheit − 32) × 5/9

Learning Outcomes

Through this project, I learned about Python functions, GUI development, conditional statements, and exception handling.
